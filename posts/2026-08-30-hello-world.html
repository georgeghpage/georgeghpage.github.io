This is the first post — replace it with your own. Posts are plain HTML files in posts/, so you can write exactly what you want with no build step and no framework.

The easiest way to start a new post is from the template:

./new-post.sh my-first-post "My first post"

Writing in plain HTML

You mostly need a handful of tags:

  • <p> paragraphs
  • <h2> / <h3> sections
  • <ul> / <ol> lists
  • <pre><code> code blocks
  • <blockquote> quotes
Keep it simple. The design does the work; you just write.

When the post is done, add one line to blog.html so it shows up in the list — the helper script prints that line for you.
